# Uber Trip Analysis – NYC

## Project Overview
This project analyzes Uber pickup data in New York City to understand trip patterns, demand trends, and operational distribution using Python.

## Project Objectives
- Analyze Uber pickup demand by hour and day.
- Identify peak pickup periods.
- Examine Uber pickup distribution across different bases.
- Discover useful patterns and insights from trip data.

## Dataset
- **Dataset:** Uber Pickups in New York City – April 2014
- **Records:** 564,516
- **Source:** [FiveThirtyEight Uber TLC FOIL Response Dataset](https://github.com/fivethirtyeight/uber-tlc-foil-response)

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data loading and inspection
- Date and time analysis
- Hourly pickup analysis
- Daily pickup analysis
- Base-wise pickup analysis
- Data visualization

## Key Findings
- Identified pickup demand patterns across different hours.
- Compared daily pickup activity.
- Identified the base with the highest number of recorded pickups.
- Used visualizations to understand demand distribution.
